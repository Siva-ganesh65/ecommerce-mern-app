# 🛒 Full-Stack E-Commerce Web Application

A full-stack e-commerce platform built with the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) featuring user authentication, product management, cart functionality, and order processing.

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js, React Hooks, React Router DOM, CSS3 |
| Backend | Node.js, Express.js, REST API |
| Database | MongoDB, Mongoose ODM |
| Auth | JWT (JSON Web Tokens) |
| Tools | Git, GitHub, Postman, VS Code |

---

## ✨ Features

- 🔐 User Registration & Login with JWT Authentication
- 🛍️ Product listing with search and category filter
- 🛒 Add to Cart, Update Quantity, Remove items
- 📦 Order placement and order history
- 🔑 Role-based access control (Admin / Customer)
- 📱 Fully Responsive UI

## 📡 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/auth/register | Register new user |
| POST | /api/auth/login | Login user |
| GET | /api/products | Get all products |
| POST | /api/products | Add product (Admin) |
| POST | /api/orders | Place an order |
| GET | /api/orders/:id | Get order details |
